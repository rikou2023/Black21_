# BLACK21 狼人 · 人设设定集（定稿 v1）

> 作者:李航｜定稿日期:2026-07-16｜依据本人访谈作答整理。
> 本设定为角色的完整独创构思,是形象著作权的核心依据之一。

---

## 一句话定义
**一只外表很酷、内心反差的搞怪技术狼。**

## 基本信息
- **英文名 / 品牌名**:BLACK21
- **中文名**:黑二幺(谐音昵称「二丫」)
- **物种**:拟人化灰狼(anthro grey wolf)
- **性别 / 年龄感**:男性,20–30 岁
- **定位**:李航的**化身**、**守护神**、以及个人品牌**门面**

## 名字与「21」的含义
- 「21」= 李航的**生日** + **幸运数**,是这个形象的私人印记。
- 希望别人想起这个形象时,第一个冒出的词就是 **「黑21 / BLACK21」**。

## 性格内核
- **外表**:冷峻、帅气、酷。
- **内心**:热情、善良、热心、搞笑——是个**小甜心**。
- **核心特质**:**理性**(最戳作者本人的一点)。
- **反差萌**(重要人设点):喜欢反差——男扮女装、撒娇、搞怪,外冷内热。
- **软肋**:自己心爱的人(老婆)。
- **雷点**:讨厌被约束;讨厌被误解;讨厌被当成格格不入的异类。

## 情绪表现(与表情包对应)
| 情绪 | 表现 |
|---|---|
| 开心 | 笑得合不拢嘴 |
| 得意 | 嘴角压不住的笑 |
| 无语 | 人中向下、嘴角弯下去 |
| 疲惫 | 眼神涣散、嘴巴微张 |
| 面对 bug / deadline | 先冷笑或哈哈大笑,然后一脸无语 |

## 声音与语气
- **男低音**。
- 中 / 日 / 英**混说**,爱**自我吐槽**。
- 口头禅:暂无(留待日后自然长出)。

## 招牌动作 / 习惯
- **咬指甲**(标志性小动作)。

## 视觉识别点
- 已确立:冷灰毛、**冰蓝(青)发光眼**、黑+青**电竞耳机**(耳罩发光狼头 emblem)、黑连帽衫+青描边、蓬松灰白尾。
- **独家标志**:**胸徽**。
- **「BLACK21 / 21」出现位置**:耳机、鞋子、衣服。
- **绝不可改的元素**:**带「21」的耳机**(形象底线)。
- **眼神/表情基调**:帅气 + 搞怪。
- 品牌色:黑 `#0A0A0A` / 深底 `#06080E` / 强调青 `#00B2E0`。
- 设计动因:耳机=职业(工程师);青+夜色=狼的雄性气质;像素=作者偏爱的风格。

## 背景故事 / 世界观
- **由来**:李航捡到一枚**蛋**,蛋里**孵出**了这只狼。
- **世界**:它的世界就是**李航的世界**——它就是"另一个我",活在同一个世界里。
- **日常**:靠**写代码**为生;和李航一起**打游戏、写代码**。
- **社交**:没有固定伙伴/宿敌——它其实**更喜欢一个人**。

## 它与李航的关系
- 它是李航的**化身**。
- 透过它,大约展现"李航"本人的**一半**。

## 使用场景 / 调性
- 出场时机:**写代码时、心动时、装酷时**。
- 整体调性:**外表专业酷,内心小甜心**(切换)。

## 底线(绝不触碰)
- 绝不做**违法**的事。
- 绝不做**耻辱**的事。

## 终极愿景
- 让李航借由这个形象,成为一个**无忧无虑的自己**。
