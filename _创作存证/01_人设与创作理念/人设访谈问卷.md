# BLACK21 狼人 · 人设访谈问卷（苏格拉底式）

## 第一组 · 源头(你为什么要它)
1. 你第一次萌生"要有一个属于自己的形象"是在什么时刻、什么心情下?
2. 为什么是「狼」?狼对你意味着什么?
3. 这个形象对你个人是什么?——另一个我 / 守护者 / 招牌门面 / 伙伴 / 其它?
4. 为什么选「耳机 + 青色 + 夜色/像素」这套元素?它们各自击中你什么?
5. 十年后别人想起这只狼,你希望他们脑中冒出的**第一个词**是什么?

## 第二组 · 名字与身份
6. 它作为"角色"有没有自己的名字/昵称?(还是就叫 BLACK21?)
7. 「21」对你有含义吗?(生日 / 幸运数 / 某个梗 / 无意义?)
8. 它有性别吗?年龄感?(少年 / 青年 / 无龄感?)

## 第三组 · 性格内核
9. 用 3–5 个形容词描述它的性格。
10. 它最"戳你"的一个特质是什么?为什么?
11. 它有没有反差 / 软肋?(外表酷、其实……)
12. 它面对难题 / bug / deadline 时什么反应?
13. 它讨厌什么?会为什么生气?

## 第四组 · 背景故事 / 世界观
14. 它从哪来?(东京 / 数字世界 / 你脑补的某设定?)
15. 它靠什么"生活"、平时做什么?
16. 它所在的世界什么样?(赛博东京 / 纯数字空间 / 现实带点魔幻?)
17. 有没有伙伴 / 宿敌 / 其他角色?(可先留白)

## 第五组 · 独家识别点(既立作者性,也防撞款)
18. 除了耳机和青眼,想给它一个"只属于它"的独家标志吗?(胸徽 / 纹样 / 道具 / 配饰 / 伤疤…)
19. 「21」要不要出现在造型里?放哪?
20. 哪个细节你特别在意、**绝不能被改**?
21. 它的眼神 / 表情,最关键要传达什么感觉?

## 第六组 · 声音与语气
22. 如果它会说话,什么语气?(冷淡 / 贫嘴 / 中二 / 温和 / …)
23. 中 / 日 / 英,它主要"说"哪种?会混吗?
24. 有没有口头禅?(现编一个也行)

## 第七组 · 行为与情绪
25. 它的招牌动作 / pose 是什么?
26. 开心 / 得意 / 无语 / 疲惫时,分别什么样?(呼应表情包)
27. 有没有习惯性小动作?

## 第八组 · 它和你的关系
28. 它是"你本人的化身",还是"独立于你的一个角色"?
29. 你希望别人透过它,认识"李航"到什么程度?

## 第九组 · 调性边界(用途与底线)
30. 它会出现在哪些地方?(网站 / GitHub / 博客 / 表情包 / 周边?)
31. 有没有它"绝对不会做 / 不会说"的事?(守住调性)
32. 它整体偏"专业酷",还是"可爱亲和",还是两者切换?

## 第十组 · 一句话收束
33. 用**一句话**定义这只狼(像一句 slogan)。
34. 你希望这个形象最终帮你达成什么?
