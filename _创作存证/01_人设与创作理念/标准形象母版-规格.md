# BLACK21 标准形象母版 · 规格书

> 目标:做出**唯一一张权威"母版"形象**——"这就是 BLACK21 狼"。其它所有图(表情/场景/网站)都以它为准,登记/维权也以它为核心。
> 用法:拿这份去**指挥 ChatGPT 生成/修改**,并逐项**验收**。作者:李航｜日期:____________

---

## 一、母版包含（建议 2 张)

- **A. 全身正面立绘**(主母版):角色站姿、清晰、**透明底或深底**。
- **B. 头部特写**(头像用):肩以上、3/4 侧。

## 二、必含身份元素（验收硬指标,缺一不可）

- [ ] **带「21」的电竞耳机**（耳罩发光狼头 emblem)——**核心标识,绝不可改**
- [ ] **胸徽**（你的独家标志;造型由你定)
- [ ] **「BLACK21 / 21」** 出现在:**耳机、鞋子、衣服**
- [ ] **冰蓝(青)发光眼**
- [ ] 冷灰毛 + 黑连帽衫(青拉链/描边) + 深色工装裤 + 板鞋 + 蓬松灰白尾
- [ ] 表情基调:帅气(母版取中性帅气即可,搞怪版另做)

## 三、配色（精确值）

| 用途 | 色值 |
|---|---|
| 主黑 | `#0A0A0A` |
| 深底 | `#06080E` |
| 强调青(眼/发光/描边/字) | `#00B2E0` |

## 四、画风与格式

- 画风:pixel-art anime / 赛博,与现有角色图一致。
- 分辨率:尽量高;**透明底**(便于抠图与合成);能出**分层文件**更好。
- **不要 AI 乱写文字**——「BLACK21/21」若 AI 写不准,留位后期由你手动写清。

## 五、指挥 ChatGPT 的起点提示词

以现有肖像 `logo.png` / 全身图为参考(垫图 + 固定 seed),在角色提示词 ③(全身站姿)基础上追加:

```
..., a distinct chest emblem badge on the hoodie, "BLACK21" text printed on the headphone band / shoes / sleeve, keep the "21" gaming headphones as the signature element, strict palette: black #0A0A0A, dark navy #06080E, cyan #00B2E0 accents only, transparent background, high resolution
```
(每轮改动记进 `../02_提示词迭代记录/`)

## 六、验收 + 你的"人手参与"（关键)

1. 用上面第二节逐项打勾验收;
2. **你本人**至少做几处实操(即使简单):亲手放/画**胸徽**、写/摆「21」、按品牌青调色、修边——存 PSD + 前后对比到 `../04`;
3. 通过后,定为**标准形象母版**,存 `../05_定稿成品/`,并 `git commit` 打时间戳;
4. 之后所有衍生图都以此母版为基准。
