# BLACK21 形象 · 人工深度修改 操作清单

> **这一步是可版权性的命门。** 把 AI 输出当"草稿/素材",经你**亲手、实质性**加工后,成品才承载你的独创性表达,著作权才立得住。
> 作者:李航｜开始日期:____________

---

## 一、原则(先记住)

- AI 图 = **原材料**,不是成品。
- 目标:让成品和 AI 原图**肉眼可见地不同**,且你能指着说"这几十处都是我改的、为什么这么改"。
- 每一处改动最好**呼应你的人设**(见 `../01/人设设定集-BLACK21.md`)——改动越是"你的创作意图"的体现,越有力。

## 二、工具(任选)

- **Photoshop**(有就用);
- **Photopea**(免费、浏览器、兼容 PSD,推荐)——photopea.com;
- **Krita**(免费桌面);像素精修可用 **Aseprite**。
- 关键:**用带图层的软件**,保留分层源文件(`.psd` / `.kra` / `.ase`)。

## 三、改什么(勾选,尽量多做几项)

结合你定的人设,建议每张至少做到 4–5 项:

- [ ] **重绘/修整关键线条**:狼头轮廓、耳机、五官,手动重画或大幅修线
- [ ] **加入你的原创标志**:
  - [ ] **胸徽**(你定的独家标志——自己设计造型画上去)
  - [ ] **「BLACK21 / 21」** 放到**耳机 / 鞋子 / 衣服**上
  - [ ] 确认**带「21」的耳机**这个"绝不可改"的核心标识清晰到位
- [ ] **配色重制**:按品牌色手动重新上色/调色(黑 `#0A0A0A` / 深底 `#06080E` / 强调青 `#00B2E0`)
- [ ] **调整比例/姿态/构图**:改动身形、动作、镜头,不与原输出雷同
- [ ] **表情按人设重画**:呼应你定的情绪语言(得意=嘴角压不住;无语=人中向下嘴弯下…)
- [ ] **加原创小细节**:咬指甲的招牌动作、专属纹样/道具
- [ ] **拼合再创作**:把多张素材/元素重组成新画面
- [ ] **逐像素精修**:修边、清瑕、统一像素颗粒

> 心法:改到你敢说"这是我基于 AI 草稿再创作的作品",而不是"AI 给我出的图"。

## 四、每张怎么留证(三件套 + 文字)

对每一张要定稿的图,产出并归档:

1. **AI 原图**(未改的)→ 放 `../03_AI生成原图_含废稿/`
2. **分层源文件**(PSD 等,能看到你的图层/改动)→ 放 `04`(本目录)
3. **前后对比图**(左 AI 原图 / 右 你的定稿,拼一张)→ 放 `04`
4. **一段文字说明**(用下面模板)→ 记录改了什么、为什么
5. 定稿成品 → 放 `../05_定稿成品/`

**命名带日期版本**:如 `肖像_v3_20260720.psd`、`肖像_对比_20260720.png`。

## 五、每张修改记录模板(复制填写)

```
【图名】：肖像 / 招手 / 全身 …
【日期】：2026-__-__
【工具】：Photopea / PS …
【AI 原图文件】：03/……png
【分层源文件】：04/……psd
【我做的修改（逐条）】：
  1. 重绘了狼头下颌与耳机轮廓线；
  2. 手绘加入胸徽（造型：____），并在耳机侧标注「21」；
  3. 按品牌青 #00B2E0 重新调整发光与描边；
  4. 调整了站姿重心 / 表情（改为“得意，嘴角压不住”）；
  5. 逐像素修了边缘毛刺。
【为什么这么改（创作意图）】：
  为呼应“外冷内甜、带 21 印记”的人设设定……
【成品文件】：05/……png
```

## 六、优先级 + 收尾

1. **先改核心 3 张**:肖像、招手、全身站姿(网站/头像主用)。
2. 每改完一张,**归档三件套 + 记录**。
3. 阶段性地**回到 git 提交一次**(命令见 `../版权与存证-指引.md`),给修改过程也打上时间戳。
4. 核心图定稿后,考虑**中国作品登记**(用 `../01/创作理念说明.md` 当说明书)。

> 提醒:登记说明书里**如实写"AI 辅助 + 人工独创性加工"**,并重点陈述你在本清单里做的实质修改——别声称"纯手绘"。
