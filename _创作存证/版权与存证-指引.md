## 一、AI 生成形象能不能有版权?(按地区)

**核心原则**:著作权保护"人类的独创性表达"。纯 AI 自动输出(一句提示词点一下)的可版权性在很多地区是**存疑的**;**人的创作贡献越多、证据越足,越受保护。**

| 地区 | 现状 | 对你的意义 |
|---|---|---|
| **中国** | 北京互联网法院 2023 判例:人有独创性智力投入的 AI 图**可构成作品**,著作权归人。 | **最有利、最可操作。建议重点走中国作品登记。** |
| **日本**(你居住地) | 创作即自动受保护、**无需登记**;但需人的「創作意図 + 創作的寄与」(文化庁 2024 指南)。 | 保护自动生效;登记(文化庁/SOFTIC)是补充证据。 |
| **美国** | 美国版权局目前**不给纯 AI 输出**版权,仅保护人类创作/编排的部分。 | 若面向国际市场需谨慎,靠"人工修改+人设"部分主张。 |

**结论**:你要做的正是把它从"纯 AI 输出"变成"有大量人类创作的作品"——靠下面四根杠杆。

## 二、让形象"可版权"的四根杠杆

1. **人设构思(创作意图)**:名字、性格、故事、世界观、设计理念——由你原创。见 `01_人设与创作理念`。
2. **独创性智力投入(过程)**:多轮提示词设计与调试、参数选择、大量筛选——留完整日志。见 `02` `03`。
3. **实质性人工修改(最关键)**:AI 图当"素材",你**亲手**做实质加工。见下方清单。
4. **选择与编排**:多个元素的独创性组合、整套形象系统的编排。

## 三、人工深度修改清单(这一步必须你亲手做)

把 AI 输出当草稿,至少做到以下几项并**留分层源文件 + 修改前后对比**:

- [ ] **重绘/描线**:关键线条(狼头轮廓、耳机、五官)手动重画或大幅修整
- [ ] **调整比例/结构**:改动身形、姿态、构图,不与原输出一致
- [ ] **配色重制**:按品牌色手动重新上色/调色
- [ ] **加入原创元素**:你设计的标志物(如胸前徽章、特定纹样、道具)
- [ ] **拼合/再创作**:多张素材重组成新画面
- [ ] **清理与精修**:逐像素修边、修瑕

> 记录方式:每张定稿都保存 **PSD/分层文件** + 一张 `修改前 vs 修改后` 对比图 + 一句话说明"改了什么、为什么"。放 `04_人工修改过程`。

## 四、创作证据链(全程留痕)

- **时间线**:提示词 → 生成原图(含废稿)→ 人工修改 → 定稿,每步带**日期**。
- **不删废稿**:未采用的生成结果是"筛选投入"的证据。
- **Git 时间戳**(推荐):
  1. 在 `Black21_` 或 `_创作存证` 里 `git init`;
  2. 定期 `git add . && git commit -m "..."`,每次 commit 自带不可回改的时间与内容哈希;
  3. push 到私有远程仓库(GitHub/Gitee)= 第三方时间佐证。
- **第三方存证**(更强):
  - 中国:可信时间戳(联合信任时间戳服务中心 TSA)、区块链存证(如"保全网"、蚂蚁链等);
  - 对关键定稿文件做**哈希 + 可信时间戳**,固定"某时刻已存在此文件"。

## 五、版权登记(把证据变成官方凭证)

**中国 · 作品自愿登记(推荐先做这个)**
- 机构:中国版权保护中心 / 地方版权局(部分省市)。
- 作品类型:美术作品。
- 需备:作品样本、作品说明(创作过程/独创性说明——正好用 `01` 的理念文档)、身份证明、权利归属声明。
- 产出:**作品登记证书**,维权时是强力初步证据。
- 提示:说明书里**如实写"AI 辅助 + 人工独创性加工"**,重点陈述你的智力投入,别声称"纯手绘"。

**日本**
- 无需登记即受保护;如需可做**実名登録 / 第一発行年月日登録**(文化庁,程序性,增强证明)。

**商标(另一条腿,建议一并考虑)**
- 若 BLACK21 + 狼头要长期当**品牌标识**用,商标注册(中国商标局 / 日本特許庁)对"防盗用、防冒用"往往比著作权更实用、更硬。
- 类别按用途选(如第 9 类软件、第 42 类技术服务、第 41 类内容等)——具体找代理确认。

## 六、防"侵权"(别撞到别人已有形象)

- "戴耳机的赛博狼人"是热门题材,**定稿前做查重**:
  - 对定稿图做**反向图搜**(Google 图片、SauceNAO、TinEye);
  - 检索是否与知名 furry/电竞狼吉祥物高度相似。
- 靠**独特识别点**拉开距离(专属徽章、配色比例、特定造型语言)。
- 保留"独立创作"证据(过程链本身也能佐证非抄袭)。
