# BLACK21 形象 · 创作存证总说明

本目录用于**证明"BLACK21 狼人形象"是李航独创的作品**,以最大化著作权保护、防止被盗用、并留存完整创作证据链。

> ⚠️ 本套材料由 AI 助手协助搭建框架,**所有创作决策由李航本人做出**。正式登记与维权请咨询专业知识产权律师。

## 文件夹用途

| 文件夹 | 放什么 |
|---|---|
| `01_人设与创作理念` | 设定集、创作理念说明(为什么这样设计)——体现"创作意图" |
| `02_提示词迭代记录` | 每一轮提示词 + 修改原因,展示"独创性智力投入" |
| `03_AI生成原图_含废稿` | 所有生成结果,**包括没选用的废稿**(废稿也是筛选投入的证据) |
| `04_人工修改过程` | 人工改图的**分层源文件(PSD)**、修改前后对比、修改步骤记录 |
| `05_定稿成品` | 最终定稿的形象文件 |
| `06_登记与存证材料` | 时间戳/存证凭证、版权登记申请材料与证书 |

## 归档铁律

1. **文件名带日期**:如 `20260716_招手_v3.png`。
2. **不要删废稿**:失败/未采用的也留着(是创作过程的证据)。
3. **每一步留痕**:提示词、参数、生成时间、谁改的、改了什么。
4. **人工修改是关键**:AI 出的只是"素材",必须有你亲手、实质性的加工(见指引文档)。

## 建议:用 Git 给整个目录做时间戳

在本目录初始化 git、定期 commit,每次 commit 都是一个带时间的不可篡改记录(配合远程仓库/存证服务更强)。详见 `版权与存证-指引.md`。
