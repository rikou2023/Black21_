# BLACK21 耳机狼人 — AI 生成提示词全集（10 张）

> 每条都**自带完整风格描述**,单独复制哪条都能用,不用拼接。

## ⚠️ 两个铁律（每张都适用）

1. **上传 `logo.png` 当角色参考图**（MJ:`--cref 图链接`;即梦 / Nano Banana / SD:放到「参考图 / 垫图」）——否则每张的狼会长得不一样。
2. 拿到满意的第一张后,**记住它的种子号(seed)**,后面所有图复用同一 seed,角色才稳定统一。

**通用负面词**（填到 Negative 栏）:

```
text, letters, watermark, signature, logo text, extra limbs, deformed hands, blurry, low-res, cluttered background, purple pink gradient, oversaturated
```

**出图要求**:尽量要**深底或透明底**（方便抠出来放进暗黑页面）,分辨率越高越好,每条多出几张挑最像的。
